# Node.js 参数格式完整对比

## 📋 参数格式总览表

| 格式 | 语法示例 | 解析结果 | 使用场景 | 优点 | 缺点 |
|------|---------|---------|---------|------|------|
| **位置参数** | `node script.js arg1 arg2` | `['arg1', 'arg2']` | 文件路径、固定顺序输入 | 简单直接 | 顺序敏感、不清晰 |
| **单横线** | `node script.js -v -d` | `{ v: true, d: true }` | 布尔标志、简写选项 | 简洁、可组合 | 只能单字符 |
| **单横线组合** | `node script.js -vdh` | `{ v: true, d: true, h: true }` | 多个布尔标志 | 输入快速 | 可读性稍差 |
| **单横线+值** | `node script.js -n John` | `{ n: 'John' }` | 简短的键值对 | 简洁 | 不够明确 |
| **单横线+等号** | `node script.js -n=John` | `{ n: 'John' }` | 明确的键值对 | 无歧义 | 不常见 |
| **双横线** | `node script.js --verbose` | `{ verbose: true }` | 布尔标志 | 自描述、清晰 | 较长 |
| **双横线+值** | `node script.js --name John` | `{ name: 'John' }` | 键值对选项 | 清晰易读 | 需要空格 |
| **双横线+等号** | `node script.js --name=John` | `{ name: 'John' }` | 明确的键值对 | 无歧义、清晰 | 略长 |
| **环境变量** | `PORT=3000 node script.js` | `process.env.PORT = '3000'` | 配置、敏感信息 | 适合部署 | 类型都是字符串 |
| **-- 分隔符** | `node script.js -- -file.txt` | `['--': ['-file.txt']]` | 文件名以-开头 | 避免歧义 | 额外语法 |

## 🔄 同一参数的不同写法

### 布尔标志

```bash
# 以下都表示启用 verbose 模式
node script.js -v
node script.js --verbose
node script.js -v true        # 不推荐
node script.js --verbose=true # 不推荐
```

### 键值对选项

```bash
# 以下都表示设置 name 为 John
node script.js -n John
node script.js -n=John
node script.js --name John
node script.js --name=John   # 推荐：最清晰
```

### 数字类型

```bash
# 以下都表示设置 port 为 8080
node script.js -p 8080
node script.js -p=8080
node script.js --port 8080
node script.js --port=8080   # 推荐

# 注意：解析后可能是字符串或数字，取决于解析库
```

### 数组/列表

```bash
# 多次指定同一选项
node script.js -t tag1 -t tag2 -t tag3
node script.js --tag tag1 --tag tag2 --tag tag3

# 使用 yargs 时可以：
node script.js --tags tag1 tag2 tag3

# 解析结果：{ tags: ['tag1', 'tag2', 'tag3'] }
```

## 📊 解析库对比

### 1. 原生 process.argv

```javascript
// 输入: node script.js -a --name=John file.txt
process.argv
// 输出: 
[
  '/usr/local/bin/node',
  '/path/to/script.js',
  '-a',
  '--name=John',
  'file.txt'
]
```

**特点：**
- ✓ 无依赖
- ✓ 完全控制
- ✗ 需要手动解析
- ✗ 代码量大

---

### 2. minimist

```javascript
// 输入: node script.js -a --name=John file.txt
const args = minimist(process.argv.slice(2))
// 输出:
{
  _: ['file.txt'],
  a: true,
  name: 'John'
}
```

**特点：**
- ✓ 极小（~5KB）
- ✓ 自动解析
- ✓ 简单易用
- ✗ 无帮助生成
- ✗ 验证功能弱

---

### 3. commander

```javascript
// 输入: node script.js -a --name John file.txt
program
  .option('-a, --all')
  .option('-n, --name <name>')
  .argument('[file]')
  .parse()

const options = program.opts()
// 输出:
{ all: true, name: 'John' }

const files = program.args
// 输出: ['file.txt']
```

**特点：**
- ✓ 自动帮助信息
- ✓ 声明式 API
- ✓ 支持子命令
- ✓ 类型转换
- ✗ 中等大小（~50KB）

---

### 4. yargs

```javascript
// 输入: node script.js -a --name John --port 8080 file.txt
const argv = yargs(hideBin(process.argv))
  .option('a', { type: 'boolean' })
  .option('name', { type: 'string' })
  .option('port', { type: 'number' })
  .parse()

// 输出:
{
  _: ['file.txt'],
  a: true,
  name: 'John',
  port: 8080  // 注意：自动转换为数字！
}
```

**特点：**
- ✓ 功能最强大
- ✓ 类型验证
- ✓ 参数验证
- ✓ choices 限制
- ✓ 自动帮助
- ✗ 体积较大（~200KB）

## 🎯 实际使用对比

### 场景 1：简单脚本

```bash
# 任务：复制文件，可选 verbose 模式
node copy.js source.txt dest.txt --verbose
```

**推荐：** 原生 `process.argv` 或 `minimist`

```javascript
// 原生方式
const [source, dest] = process.argv.slice(2);
const verbose = process.argv.includes('--verbose');

// minimist 方式
const args = minimist(process.argv.slice(2));
const [source, dest] = args._;
const verbose = args.verbose;
```

---

### 场景 2：构建工具

```bash
# 任务：构建项目，多个选项
node build.js --env production --minify --sourcemap
```

**推荐：** `commander`

```javascript
program
  .option('-e, --env <env>', '环境', 'development')
  .option('--minify', '压缩代码')
  .option('--sourcemap', '生成 sourcemap')
  .parse();
```

---

### 场景 3：复杂 CLI 工具

```bash
# 任务：CLI 工具，需要验证
node cli.js deploy --env production --region us-east-1 --instance-count 3
```

**推荐：** `yargs`

```javascript
yargs
  .command('deploy', '部署应用')
  .option('env', {
    choices: ['development', 'staging', 'production'],
    demandOption: true
  })
  .option('region', {
    type: 'string',
    demandOption: true
  })
  .option('instance-count', {
    type: 'number',
    default: 1
  })
  .parse();
```

## 🔢 类型处理对比

### 数字

```javascript
// process.argv - 都是字符串
process.argv[2] // '8080'

// minimist - 自动推断（不可靠）
minimist(['--port', '8080']) // { port: 8080 } - 数字
minimist(['--port=8080'])    // { port: 8080 } - 数字
minimist(['--name', '123'])  // { name: 123 } - 会被转为数字！

// commander - 需要指定转换函数
.option('-p, --port <port>', '端口', parseInt)

// yargs - 指定类型，自动转换
.option('port', { type: 'number' })
```

### 布尔值

```javascript
// process.argv - 需要手动判断
const debug = process.argv.includes('--debug')

// minimist - 自动识别
minimist(['--debug'])      // { debug: true }
minimist(['--debug=true']) // { debug: true }

// commander - 声明为布尔值
.option('-d, --debug', '调试模式')

// yargs - 指定类型
.option('debug', { type: 'boolean' })
```

### 数组

```javascript
// process.argv - 需要手动处理
const tags = process.argv.filter((arg, i) => 
  process.argv[i-1] === '--tag'
)

// minimist - 自动处理重复的选项
minimist(['-t', 'a', '-t', 'b'])  // { t: ['a', 'b'] }

// commander - 需要自定义处理
.option('-t, --tag <tag>', '标签', collect, [])

// yargs - 原生支持
.option('tags', { type: 'array' })
```

## 📝 环境变量 vs 命令行参数

| 特性 | 环境变量 | 命令行参数 |
|------|---------|-----------|
| **语法** | `KEY=value node script.js` | `node script.js --key value` |
| **获取** | `process.env.KEY` | 解析库或 `process.argv` |
| **类型** | 始终是字符串 | 可以是多种类型 |
| **适用场景** | 配置、密钥、部署设置 | 运行选项、临时覆盖 |
| **可见性** | 整个进程及子进程 | 仅当前脚本 |
| **持久性** | 可以系统级设置 | 每次运行时指定 |
| **安全性** | 适合敏感信息（不在命令历史） | 会记录在命令历史 |
| **优先级** | 中等 | 最高 |

## 🎓 最佳实践

### 1. 命名规范

```bash
# ✓ 好的命名
node script.js --verbose --debug --output-dir ./dist

# ✗ 避免的命名
node script.js -v -d -o ./dist  # 不够清晰（除非很常用）
```

### 2. 提供别名

```bash
# 同时支持短选项和长选项
node script.js -v          # 快速输入
node script.js --verbose   # 清晰易读
```

### 3. 使用等号形式避免歧义

```bash
# 推荐：使用等号
node script.js --name=John --age=25

# 不推荐：可能产生歧义
node script.js --name John --age 25
```

### 4. 参数分组

```bash
# 标志放前面，键值对在中间，位置参数在最后
node script.js --verbose --debug --name John --port 8080 file1.txt file2.txt
```

### 5. 配置优先级

```javascript
// 命令行 > 环境变量 > 配置文件 > 默认值
const port = 
  args.port ||              // 1. 命令行参数
  process.env.PORT ||       // 2. 环境变量
  config.port ||            // 3. 配置文件
  3000;                     // 4. 默认值
```

## 🧪 测试命令集合

```bash
# 基础测试
node script.js
node script.js -h
node script.js --help

# 单个选项
node script.js -v
node script.js --verbose

# 组合选项
node script.js -vd
node script.js --verbose --debug

# 键值对
node script.js --name=John
node script.js --name John
node script.js -n John

# 多个参数
node script.js -vd --name John --port 8080

# 位置参数
node script.js file1.txt file2.txt
node script.js -v file1.txt file2.txt

# 环境变量
PORT=8080 node script.js
PORT=8080 NODE_ENV=production node script.js

# 组合使用
PORT=8080 node script.js -vd --name John file1.txt file2.txt

# npm scripts
npm run start
npm run start -- --port 8080
npm run start -- -vd --name John

# 特殊情况
node script.js -- -file-with-dash.txt
node script.js --config -- -special.txt
```
